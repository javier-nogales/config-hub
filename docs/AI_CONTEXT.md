# Config Hub – AI Context

## Repository

<https://github.com/javier-nogales/config-hub>

## Goal of the project

Learning project to consolidate backend skills and practice clean architecture.

Not intended to be a production feature flag platform like LaunchDarkly or Unleash.

Focus:

- REST API design
- backend implementation fluency
- architecture evolution

## Stack

- Java
- Spring Boot
- JPA / Hibernate
- PostgreSQL (maybe)
- REST API

## Architectural principles

- Keep the model small
- Avoid overengineering
- Prefer simple layers first
- Refactor architecture later (iteration 4)

## Learning goals

1. Fluency implementing REST APIs
2. Correct HTTP semantics (ETag, caching)
3. Iterative architecture evolution
4. Backend confidence

## Non-goals

- Full feature flag platform
- Distributed system
- Complex event architecture
